# Quoted Message Explanation

用户引用另一人的话并请求解释时，先读取原话、请求者和表达者人物画像，再按需要读取 Dictionary、已确认 Consensus 和 Project Memory。

如果入口提供明确的 Human Event 或 Topic ID，再读取对应动态上下文；没有 ID 时不得按相似文字猜历史归属。输出分开说明原话、项目上下文、术语、歧义和澄清问题，不替发言者补充结论，不自动创建 Card、Topic、Task 或 Memory。
