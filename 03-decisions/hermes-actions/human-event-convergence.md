# Human Event Convergence

使用 transcript、Hermes Personal Card 和 Zac/Vivi accepted Personal Card 收敛 Human Event。先更新同一 Human Event 的总结，再判断 Topic 是复用还是新建，最后决定 Task。

冲突、缺少证据或无法可靠归属的内容进入 Manager Review。只有明确确认的内容才能物化；Memory 和 Method 仍遵循显式确认及来源规则。
